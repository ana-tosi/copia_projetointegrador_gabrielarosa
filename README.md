<h1 align='center'>PROJETO INTEGRADOR I </h1>
<h2 align='center'>Sistema web para gerenciamento e controle de serviços em embarcações de uma Marina.</h2>

## 🛠️ Descrição do Projeto
Este Projeto foi desenvolvido na disciplina Projeto Integrador da UNIVESP e consiste no desenvolvimento de um sistema web para gerenciamento e controle de serviços realizados em embarcações em uma marina. A aplicação foi construída utilizando um framework web e tem como objetivo otimizar o registro de serviços, o gerenciamento de informações e o acesso a dados relevantes para apoio à gestão operacional.
